# Changelog

All notable changes to **Dialogue Graph Toolkit (Pro & Lite)** are documented here.

## [1.0.0] - 2026-11-15
### Dialogue Graph Toolkit Pro
- Visual Node Graph Editor (`Start`, `Sentence`, `Choice`, `SetVariable`, `Condition`, `End`) with 20%–200% zoom, multi-node clipboard, and 60-step Undo/Redo.
- In-Canvas Live Simulation Terminal (PiP HUD) with dockable mode, Live Sync, Auto-Follow, Fast Run, and Interactive Step-Back (Rewind).
- Native TextMeshPro (TMP) typewriter engine with pitch-modulated audio blips, voice dubbing clip support, and 4 advance input toggles.
- 6 UI Theme Presets and 6+2 Procedural / 9-Slice Box Shapes with live Inspector opacity sliders.
- Dynamic Head-Tracking Thought Cloud & Angry Shout Balloons with auto-flipping and screen clamping.
- 5 Choice Layout Styles and RFC 4180 CSV Localization (Excel & Google Sheets) with Zero Broken Cables Guarantee.
- 4 Built-in Asset Browsers (Audio, Character, Database Manager, Preset Browser), 1-Click Scene Setup, 3D NPC Triggers, and public C# `DialogueAPI`.

### Dialogue Graph Toolkit Lite
- Core visual node workflow (`Start`, `Sentence`, `Choice`, `End`), Slat-Accordion Shutter Toolbar, Database Manager, and Preset Browser with Snap-on-Release HUD.
- 1-Click Smart Scene Setup, native uGUI runtime with choice button pooling, `DialogueTrigger_v1_0`, and dual Legacy/New Input support.
