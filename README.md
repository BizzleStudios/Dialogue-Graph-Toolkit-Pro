## ⭐ Exclusive Pro Features

### 🎙️ 1. AI Voiceover Synthesis Engine
- Generate character voices directly inside the Unity Editor without third-party software.
- Full API integration with **ElevenLabs** and **OpenAI TTS**.
- Automatic audio clip assignment and subtitle timing generation.

### ⚡ 2. In-Canvas Live Terminal HUD
- Test conversations visually on the editor canvas **without entering Play Mode**.
- Interactive **Rewind & Step-Back**: Step backward in dialogue branches to test alternate choice paths instantly.

### ✨ 3. Native TextMeshPro (TMP) Integration
- Smooth typewriter text animations with configurable characters-per-second.
- Audio blips/beeps per character or word.
- Rich-text tags and custom font asset support out-of-the-box.

### 🎨 4. Procedural Bubble UI Themes
- Switch dialogue UI styling dynamically:
  - **Speech Bubbles** (with customizable pointer tails toward speaking characters).
  - **Thought Clouds** (for internal monologues).
  - **Manga / Comic Bursts** (for shouting and dramatic moments).
  - **Cinematic Widescreen Strips** (for cutscenes and letterboxing).
