## ⭐ Exclusive Pro Features

### 🧠 1. Quest Logic & Narrative Memory
- **SetVariable Node:** Store boolean narrative flags, quest progress, and custom string values during runtime.
- **Condition Node:** Branch dialogues dynamically based on player choices, quest status, or stats (`==`, `!=`, `>`, `<`, `>=`, `<=`).
- True non-linear narrative design for RPGs, visual novels, and adventure games.

### 🎙️ 2. AI Voiceover Synthesis Engine
- Generate expressive character voices directly inside the Unity Editor without third-party audio software.
- Full API integration with **ElevenLabs** and **OpenAI TTS**.
- Automatic audio clip assignment, playback preview, and subtitle timing synchronization.

### ⚡ 3. In-Canvas Live Terminal HUD & Rewind
- Test conversations visually on the editor canvas **without entering Play Mode**.
- **Interactive Rewind & Step-Back:** Step backwards and forwards through dialogue branches to test alternate choice paths instantly.

### ✍️ 4. Native TextMeshPro (TMP) Integration
- Smooth typewriter text animations with configurable characters-per-second typing speed.
- Audio blips / beeps per character or word for retro and modern RPG effects.
- Full rich-text tags, custom font assets, and emoji sprite support out-of-the-box.

### 💬 5. Procedural Bubble UI Themes
- Switch dialogue presentation dynamically:
  - **Speech Bubbles** (with customizable pointer tails anchored toward speaking characters).
  - **Thought Clouds** (for internal monologues).
  - **Manga / Comic Bursts** (for shouting and dramatic moments).
  - **Cinematic Widescreen Strips** (for cutscenes and letterboxed storytelling).
