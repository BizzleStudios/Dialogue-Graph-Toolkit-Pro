## ⚡ What's Included in the PRO Edition ($49.99)?

Everything needed for full commercial game narrative production:

- **🧩 Complete Visual Node Suite:** `Start`, `Sentence`, `Choice` (5 layout styles), `SetVariable`, `Condition` (`==`, `!=`, `>`, `<`, `>=`, `<=`), and `End` nodes with multi-node clipboard, 60-step Undo/Redo, and 20%–200% focal zoom.
- **📺 In-Canvas Live Simulation Terminal (PiP HUD):** Test branching conversations, variables, and conditions directly on the canvas without entering Play Mode—featuring **Interactive Step-Back (Rewind)**, Fast Run, Live Sync, Auto-Follow, and 1-click sidebar docking.
- **✍️ Native TextMeshPro (TMP) Engine:** Crisp SDF typography, configurable typewriter animation, pitch-modulated audio blips, voiceover dubbing slots, rich-text tags, click-anywhere skip, and 4 customizable advance controls.
- **💭 Dynamic Head-Tracking Thought & Shout Balloons:** Automatically transforms inner thoughts (`(Thought)`, `(...)`, `*...*`) into floating **Thought Clouds** and angry lines (`[ANGRY]`, `[SHOUT]`, `!!`) into shaking **Action Spiky Bursts**—with 3D speaker head tracking, distance scaling, edge auto-flipping, and screen clamping.
- **🎨 6 UI Themes & 6+2 Procedural Box Shapes:** Instant theme presets (*Dark Slate Modern*, *Cinematic Subtitles*, *Cyberpunk Neon*, *Anime VN*, *Action Blockbuster*, *Retro RPG*), 6 crisp main shapes (*Rectangle*, *Rounded Capsule*, *Cinema Strip*, *Speech Bubble*, *Cozy Sticker Card*, *Chamfered Tech*), optional transparent subtitles + TMP soft text shadow, and live **Box, Expressive Balloon, and Choice Button Opacity** sliders.
- **📊 RFC 4180 CSV Localization:** Full two-way Export & Import for Excel, Google Sheets, and LibreOffice with **Zero Broken Cables Guarantee** (automatically re-links choices by unique Node IDs and port indices).
- **🗄️ 4 Dedicated Asset Browsers:** Built-in mini-browsers for **Audio Clips** (live preview), **Characters & Actors**, **Master Databases** (with Diagnostics & 1-Click Backup), and **Presets** (with Story Inspector HUD).
- **👤 1-Click Smart Scene Setup & 3D NPC Triggers:** Supports `PressKeyPrompt` (stylized auto-head-aligned floating badges with bobbing), `ProximityAutoStart`, and `MouseClickRaycast` with smooth Quaternion Slerp face-to-face rotation, `Freeze Camera & Move`, and `Trigger Only Once`.
- **🔌 Public C# Scripting API (`DialogueAPI`) & Universal Input:** Clean static API (`StartDialogue`, `SetVariable`, `GetVariable`, and lifecycle events), seamless **Legacy Input + New Input System** support, and `link.xml` for IL2CPP builds.
